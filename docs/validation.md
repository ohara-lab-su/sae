# 検証記録

## 独立したクラスライブラリ

成果物には `src/sae` のみを実装パッケージとして収録しています。
旧パッケージのソースや OLD ディレクトリは同梱せず、実行時にも参照しません。
`poscar.py`、`inp_writer.py` 等にクラス本体があり、単独関数だった処理は
CoordinateTransforms、SupercellOperations、TextFiles、ElementTable、各 Writer の
メソッドへ移しています。Rvasp2cfg_nonLIB の処理も PoscarToRmcProgram.run に移しました。

## テスト結果

**1183 tests passed**（Python 3.12.11）。

- 899メソッドについて、元の算術式の構文木と移植後を比較。
  呼び出し先のクラス化に伴う修飾名だけを正規化し、演算子・被演算子を比較。
- 260件のクラス操作の引数・既定値・戻り値・例外・保持先を検証。
- 13ケースの保存済み基準結果と、数値・配列型・生成ファイルのハッシュを比較。
  VASP の座標変換・回転・出力、OpenMX の FRAC/Ang/AU、FDMNES の入力生成・
  付属 Fe データ、HiLAPW、Athena、PWscf DOS を対象とする。
- スーパーセルの反復数・原子数・座標・固定フラグ、積分DOS、原子量検索を検証。
- 実装クラスの定義場所が新しいモジュール内であることを検証。
- OpenMX DOS の動的なクラス選択と、旧パッケージ参照がないことを検証。

テストは保存済み基準値を使用し、旧ソースは必要ありません。

```sh
python -m pytest tests -q
```

## 最小限の I/F 等の修正

- VASP スーパーセルの確保数を、生成ループと同じ x*y*z に揃えた。
- 2値を受け取る呼び出しを、元からある同じ変換の2値版へ接続した。
- PWscf 積分DOSの属性名を、コンストラクタで作成される名前へ揃えた。
- 原子量検索で bytes/str の元素記号が一致するようにした。重量表は変更していない。
- 動的 import の level=-1 を Python 3 の絶対 import（0）へ修正し、
  古いクラス名を移植先の実在するクラス名に接続した。

計算式、単位変換、DOS の集計方法、配列の順序を新しい方法で置換していません。

## 範囲

すべてのコード・バージョンの実データ検証ではありません。
OpenMX 出力の設定表・擬ポテンシャル不足は、基準ケースと同じ終了を確認しています。
非直交セルのスーパーセルは元の行列処理を保持し、物理的な正しさを新たに保証していません。
コマンド群は移植先クラスへの参照に変更していますが、全コマンドの実行結果は未検証です。
Python 3.7 の検証は構文とクラス生成、数値実行テストは Python 3.12.11 で行っています。

## ビルド・独立実行

- setup.py を使用せず、pyproject.toml から wheel を作成した。
- 別の作業フォルダへ wheel をインストールした。
- 旧パッケージ名の import を強制的に失敗させる状態で、全実装モジュールの import と
  VASP 変換・FDMNES 入力生成の利用例を実行した。いずれも成功した。
- Python 3.7.9 で全324ソースの構文と11クラスの空インスタンス生成を確認した。
