# v0.1.0 検証記録（2026-10-15）

## 基準と結果

OLD版の数式・アルゴリズム・パーサーを基準とし、同じ入力に対する処理結果・生成物の保持と、
クラス化・名前空間変更によるI/Fの接続を検証する。想定した新しい計算結果へ合わせる変更はしない。

Python 3.12.11 で **1,188 tests passed**。

- 899件：保存済み移植作業用スナップショットとの算術式比較。
- 260件：中心クラスとファイル別クラスの接続、引数・既定値・戻り値・例外・状態保持。
- 13ケース：保存済みOLD基準の数値・配列型・生成ファイルのSHA256との比較。
  VASPの座標変換・回転・出力、OpenMXのFRAC/Ang/AU、FDMNES入力生成・Feデータ、
  HiLAPW、Athena、PWscf DOSを含む。
- 11件：スーパーセル生成先と戻り値の接続、積分DOS属性、元素記号の型境界、
  動的クラス選択、実装クラスの配置、旧パッケージへの実行依存がないこと。
- 5件：README/CHANGELOG原文保持、ソースコメントの個数込み保持、移植先一覧と
  既存データのハッシュ、OLD単位胞描画の記録との一致、GUIの既存変換I/Fへの接続。

```sh
python -m pytest tests -q
```

テストは保存済み基準値を使用し、OLDの存在を必要としない。
GUIの基準値は、OLDのcrystal_make_unit関数本体を変更せず、描画先を記録用オブジェクトに
置き換えて取得した12本の円柱の位置・方向・半径・色である。描画の数学的モデルを新しく作っていない。

## I/F接続として保持した修正

- スーパーセルの確保数を既存生成ループのx*y*zに一致させる。
- 2値を受け取る呼び出しを、既存の同じ変換の2値返却版へ接続する。
- PWscf積分DOSはコンストラクタが保持するinttdos_allを参照する。
- 既存の元素表のbytes記号とstr引数を比較できるようにする。表の値は変更しない。
- Python 3の絶対importと新しいクラス名・型判定参照を接続する。
- GUIの改名前の変換呼び出しとscalar戻り値の受け取りを、旧ソースの履歴に対応する
  conv_direct2cara / conv_car2carABSa に接続する。

PDOSの集計手順・行処理等に対する追加変更は取り消した。
それを正しいとする追加テスト・算術式の例外記録も配布物に含めない。

## 実行検証の範囲

全197コマンド、各計算コードの全バージョン・全実データの検証ではない。
GUI実表示とPython 3.7上の依存モジュールを含む数値処理全体は未検証。
OpenMXの外部設定表・擬ポテンシャルを必要とするケースは、基準と同じ終了も検証対象とする。
OLDの未実装メソッドや同じ終了状態を残す処理もあり、これをアルゴリズムの問題とは判定していない。
