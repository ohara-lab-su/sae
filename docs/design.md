# クラスライブラリへの実体移植設計

- 成果物の実装は sae パッケージ内で完結させる。OLD、旧プロジェクト、旧パッケージの import は使用しない。
- VASP / OpenMX / FDMNES 等のコード単位クラスが、構造・入力・出力・解析オブジェクトと書き出し操作を持つ。
- poscar.py / doscar.py / inp.py / bav.py 等には、そのデータを保持して操作するクラス本体を配置する。再エクスポートだけのファイルにしない。
- 元の単独関数は、座標変換、スーパーセル、原子情報、テキスト入力、各コードの出力等の責務に分け、各クラスのメソッドへ移す。数式と処理順序は保持する。
- 内部の依存解決は新しいクラス・メソッドの参照だけを扱い、旧実装をロードしない。
- CLI は新しいクラスライブラリを使う入口として保持する。
- パッケージ情報、依存、ファイル収録は pyproject.toml に記述し、setup.py は設けない。
- Python 3.7の構文制約を維持する。旧プロジェクトを参照できないインストール先で検証する。
